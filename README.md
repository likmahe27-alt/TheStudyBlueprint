# The Study Blueprint - Class 10 Portal & Admin System

Welcome to **The Study Blueprint**, dedicated exclusively to Class 10 students.

## 🔒 Security & Admin Access
- **Hidden Admin Link:** There are **no visible buttons or links** to the admin panel anywhere on the student portal (`index.html`). 
- **How to Access Admin:** You can access your admin dashboard privately by typing your secret URL path directly in your browser: `yourdomain.com/admin.html` (or `admin.html` when running locally).
- **Protected by PIN:** The admin page requires a passcode (`admin123`) to view and publish live files.

## 📚 Features Included
- **Notes & Complete Solutions:** All chapter notes uploaded live.
- **PYQs Analysis:** Chapter-wise trends and repeated questions.
- **Sample Papers & Our Personal Analysis:** Sample papers paired with our expert paper breakdown and strategy.
- **CBSE Notices & Official Files**
- **Live Test Center:** Embedded Google Forms for live student testing.
- **Announcements & Channel Notices**
